# Plan: Add Icon Upload to Navigation

## Goal
Add icon upload capability to navigation items in `van-ons/filament-navigation`.

## Implementation

### Step 1: Add Icon Field to Item Modal
**File**: `app/Providers/Filament/AdminPanelProvider.php`

Use the package's `withExtraFields()` method to add a FileUpload field:

```php
->plugin(
    FilamentNavigation::make()
        ->withExtraFields([
            \Filament\Forms\Components\FileUpload::make('icon')
                ->label('Icon')
                ->image()
                ->directory('navigation-icons')
                ->disk('public')
                ->imageEditor(),
        ])
)
```

### Step 2: Override Nav-Item Component
**File**: `resources/views/vendor/filament-navigation/components/nav-item.blade.php`

Create custom view to display the icon next to the label. Add icon display logic after the handle button and before the label button.

### Step 3: Update API Response
**File**: `app/Http/Resources/Web/NavigationResource.php`

Add `icon` field to the items array in `toArray()`.

## Files to Modify

1. `app/Providers/Filament/AdminPanelProvider.php` - Add `withExtraFields()`
2. `resources/views/vendor/filament-navigation/components/nav-item.blade.php` - Create (custom view)
3. `app/Http/Resources/Web/NavigationResource.php` - Add icon field
