# Plan: Style CategoryPage & HomePage to Match Template

## Goal
Restyle the Layout, NavBar, CategoryPage, TournamentCard, and HomePage to match the dark teal sports-betting aesthetic shown in `public/template.png`, using `public/background.png` as the page background.

## Design Analysis (from template.png)

- **Background**: Full-page `background.png` (dark teal geometric abstract)
- **Header**: Semi-transparent dark bar, white brand text, nav items with icon emoji + label
- **CategoryPage**: Category label with markers, large "Active tournaments" heading, decorative divider with trophy icon, tournament cards (image left, text right, status icon far right), sidebar with category image + content in a styled card
- **Cards**: Dark semi-transparent backgrounds with cyan-ish subtle borders, rounded corners
- **Accent color**: Bright teal/cyan (~`#2dd4bf` / teal-400)
- **Typography**: Large bold headings, smaller muted descriptions, date ranges with calendar icon

## Files to Modify

### 1. `src/index.css` — Theme colors
Replace the light-mode default theme with dark teal palette:
- `--color-background`: deep dark teal (~`#0a1e24`)
- `--color-foreground`: white/light
- `--color-card`: semi-transparent dark (`rgba(10, 40, 50, 0.8)`)
- `--color-primary`: bright teal accent (`#2dd4bf`)
- `--color-border`: subtle teal border (`rgba(45, 212, 191, 0.2)`)
- Add custom CSS variables for the accent color and glass-like card effect
- Remove the light-mode `@custom-variant dark` pattern since this is a dark-only design

### 2. `src/components/ui/Layout.tsx` — Background + structure
- Add `background.png` as a fixed full-page background image via Tailwind or inline style
- Overlay a semi-transparent dark layer for readability
- Remove `bg-gray-950` hardcoded class, rely on theme variables
- Ensure content area is properly positioned above the background

### 3. `src/features/menu/ui/NavBar.tsx` — Header styling
- Semi-transparent background (`backdrop-blur-sm`, dark bg with opacity)
- Bottom border in accent color (subtle)
- Brand "Predictorium" in white, bold
- Nav items: icon emoji + label, with hover effect in accent color
- Remove hamburger menu complexity for desktop (keep mobile responsive)

### 4. `src/pages/Category/CategoryPage.tsx` — Main page layout
- Use new `CategoryLabel` component for the "// CATEGORY_NAME //" header
- Large heading: "Active tournaments" (or category subtitle) in white, very large font
- Decorative horizontal divider with centered trophy/hexagon icon
- Two-column layout: tournament list (left, wider) + sidebar (right, ~320px)
- Sidebar: category icon image + content in a bordered card with semi-transparent bg
- Style the tournament list items

### 5. `src/features/tournament/types/index.ts` — Add events_count
- Add optional `events_count?: number` to TournamentSummary interface
- This allows the card to display different icons based on event count

### 6. `src/features/tournament/ui/TournamentCard.tsx` — Card design
- Dark semi-transparent card background with subtle teal border
- Left: tournament image/icon (rounded, fixed width)
- Center: title (bold white), description (muted), date range with calendar icon
- Right: hexagonal status icon container in teal accent
  - Icon selection: based on `events_count` field if available (add to TournamentSummary type)
  - Default to trophy icon; map: 0-1 events = trophy, 2-4 = flags, 5+ = star
  - Backend doesn't return events_count yet, so trophy is default for now
- Hover effect with slight brightness increase
- Use Tailwind classes only

### 7. `src/components/ui/CategoryLabel.tsx` — Reusable label component
- Reusable component for the "// CATEGORY_NAME //" style label
- Props: `name: string`, optional `className`
- Renders: `// {name} //` in uppercase, accent color, small font
- Used in CategoryPage header section

### 8. `src/pages/Home/HomePage.tsx` — Home content
- Apply same background + dark theme styling
- Style existing HTML content blocks with dark theme colors
- Match the overall aesthetic of the category page
