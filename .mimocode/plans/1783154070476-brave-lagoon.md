# Plan: Dynamic Result Form with Repeater for Positions

## Context

When creating/editing a Result, the form should dynamically adapt based on the selected ResultType's `value_type`:
- `value_type = 'positions'` → Show a Repeater to input multiple place/participant entries
- `value_type = 'participant'` → Show the existing single participant select

The `value` field (cast as `array` in the model) will store the positions data as JSON.

## Files to Modify

1. **`app/Filament/Resources/ResultResource.php`** — Main changes

## Implementation

### Step 1: Add Required Imports

Add to the use statements:
```php
use App\Models\ResultType;
use Filament\Schemas\Components\Utilities\Get;
```

### Step 2: Update `getModalForm()` Method

Replace the current form with dynamic fields:

```php
public static function getModalForm(?Result $record = null): array
{
    return [
        Forms\Components\Hidden::make('event_id')
            ->default(fn () => request()->query('event_id')),

        Forms\Components\Select::make('result_type_id')
            ->label('Result Type')
            ->relationship('resultType', 'name')
            ->required()
            ->searchable()
            ->preload()
            ->reactive()
            ->afterStateUpdated(fn ($set) => [
                $set('participant_id', null),
                $set('value', null),
            ]),

        // Single participant (for value_type = 'participant')
        Forms\Components\Select::make('participant_id')
            ->label('Participant')
            ->options(function (Get $get) {
                $resultTypeId = $get('result_type_id');
                if (!$resultTypeId) {
                    return [];
                }
                $resultType = ResultType::find($resultTypeId);
                if (!$resultType || $resultType->value_type !== 'participant') {
                    return [];
                }
                $eventId = $get('event_id');
                if (!$eventId) {
                    return [];
                }
                return \App\Models\Event::find($eventId)
                    ?->participants()
                    ->pluck('name', 'id')
                    ->toArray() ?? [];
            })
            ->searchable()
            ->preload()
            ->nullable()
            ->visible(function (Get $get) {
                $resultTypeId = $get('result_type_id');
                if (!$resultTypeId) {
                    return false;
                }
                $resultType = ResultType::find($resultTypeId);
                return $resultType && $resultType->value_type === 'participant';
            }),

        // Repeater for positions (for value_type = 'positions')
        Forms\Components\Repeater::make('value')
            ->label('Positions')
            ->schema([
                Forms\Components\TextInput::make('place')
                    ->label('Place')
                    ->numeric()
                    ->required()
                    ->minValue(1)
                    ->maxValue(999),
                Forms\Components\Select::make('participant_id')
                    ->label('Participant')
                    ->options(function () {
                        $eventId = request()->query('event_id');
                        if (!$eventId) {
                            return [];
                        }
                        return \App\Models\Event::find($eventId)
                            ?->participants()
                            ->pluck('name', 'id')
                            ->toArray() ?? [];
                    })
                    ->searchable()
                    ->preload()
                    ->required(),
            ])
            ->columns(2)
            ->defaultItems(1)
            ->addable()
            ->removable()
            ->visible(function (Get $get) {
                $resultTypeId = $get('result_type_id');
                if (!$resultTypeId) {
                    return false;
                }
                $resultType = ResultType::find($resultTypeId);
                return $resultType && $resultType->value_type === 'positions';
            }),

        Forms\Components\TextInput::make('time')
            ->numeric()
            ->nullable()
            ->label('Time (seconds)'),
    ];
}
```

**Note**: The Repeater's participant options use `request()->query('event_id')` to get the event context, consistent with how `MarketResource` handles this pattern.

### Step 3: Handle Edit Mode

When editing an existing record with `value_type = 'positions'`, the Repeater needs to hydrate the existing JSON data. The `value` field is already cast as `array` in the model, so Filament should handle this automatically.

For the participant display in the Repeater during edit, we may need to add `->afterStateHydrated()` to properly load participant names.

3. Select the positions ResultType → Repeater should appear
4. Add multiple entries with participant and place → should save as JSON array

## JSON Format

The `value` field will store:
```json
[
    {"place": 1, "participant_id": 123},
    {"place": 2, "participant_id": 456}
]
```

Note: Using `participant_id` (not `participant`) to match the existing codebase convention and database schema.
