# Plan: Install Filament Admin Panel & Configure Nginx

## Current State
- Laravel 13, PHP 8.5, MySQL 8.0 in Docker
- `.env` configured for SQLite (mismatch with Docker MySQL) — must fix first
- No admin panel, no auth scaffolding
- nginx serves `/api` → PHP-FPM, `/` → React. `/admin` currently falls through to React.

## Steps

### 1. Fix `.env` database config
**File:** `php-app/.env`
- Change `DB_CONNECTION=sqlite` → `DB_CONNECTION=mysql`
- Uncomment and set: `DB_HOST=db`, `DB_PORT=3306`, `DB_DATABASE=my_database`, `DB_USERNAME=root`, `DB_PASSWORD=root_password`

### 2. Add missing PHP extensions to Dockerfile
**File:** `php-app/Dockerfile`
- Add `intl` extension (Filament requires it for blade components)

### 3. Install Filament
```bash
docker compose up --build -d backend
docker compose exec backend composer require filament/filament
docker compose exec backend php artisan filament:install --panels
```
Use panel ID: `admin`
This creates `app/Providers/Filament/AdminPanelProvider.php` and default User resource.

### 4. Run migrations & seed admin user
```bash
docker compose exec backend php artisan migrate
docker compose exec backend php artisan make:filament-user
```
Or via tinker:
```php
App\Models\User::create(['name'=>'Admin','email'=>'admin@example.com','password'=>Hash::make('password'),'is_admin'=>true]);
```

### 5. Configure nginx for `/admin` routes
**File:** `nginx.conf`

Add before the React catch-all:
```nginx
location /admin {
    try_files $uri $uri/ /index.php?$query_string;
}
```

This routes `/admin/*` through Laravel → Filament. The existing `~ \.php$` block handles FastCGI.

### 6. Rebuild & verify
```bash
docker compose up --build -d
```
- `http://localhost/admin` → Filament login
- `http://localhost/api/ping` → still works
- `http://localhost:3000` → React dev server
