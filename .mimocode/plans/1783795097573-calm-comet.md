## Schema Issue
The `events` table has `tournament_id` (FK), not `category_id`. Need a tournament first.

## Steps

### 1. Check if a tournament already exists for this championship under category_id = 1
Run a quick DB check.

### 2. Create a Tournament record
- `category_id`: 1
- `name`: "Warm Up League GT4 Summer Cup 2026"
- `slug`: "warm-up-league-gt4-summer-cup-2026"
- `status`: "active"
- `start_date`: 2026-08-03 17:00:00
- `end_date`: 2026-08-31 17:00:00

### 3. Insert 5 Event records
Each with:
- `tournament_id`: (from step 2)
- `name`: "Round {N}. Track {Track}"
- `slug`: auto-generated from name
- `status`: "draft"
- `start_date`: the race date

### Approach
Use `php artisan tinker` or a one-off DB insert via `artisan db:seed` with a new seeder file.
