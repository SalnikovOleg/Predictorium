# Plan: EventResource — Market & Outcome Management

## Goal
Add a page to create/edit markets and their outcomes for a given event, accessible from the EventResource list and edit form. Market form is dynamic, driven by `market_templates` and their `market_type_id`.

## User Decisions
- **Outcome creation**: Auto-created on market save (not manual)
- **Coef timing**: Set later, not during market creation
- **Statement**: Strictly auto-generated from template + participant (Type 2)
- **Event context**: Always pre-filled, hidden in form

---

## Database Schema (already exists — no migrations needed)

| Table | Key columns |
|-------|-------------|
| `markets` | `id`, `event_id` (FK), `market_template_id` (FK), `description` (string) |
| `outcomes` | `id`, `market_id` (FK), `outcome_type_id` (FK), `participant_id` (nullable FK), `coef` (decimal 5,2), `result` (enum win/lose/return, nullable) |
| `market_templates` | `id`, `name`, `category_id`, `market_type_id` (FK), `outcome_type_ids` (JSON), `param1` (int), `param2` (int) |
| `tournament_configs` | `id`, `market_template_ids` (JSON array of ints) |

**Relationship chain**: `event → tournament → tournament.config → config.market_template_ids → MarketTemplate records`

---

## Market Type Logic

| Type | Statement | Outcomes to create | User input |
|------|-----------|-------------------|------------|
| 1 (Boolean) | Template name as-is | Yes + No | None |
| 2 (Participant Boolean) | Template name + " — " + participant name | Yes + No | Single participant select |
| 3 (Selection) | Template name as-is | N participant outcomes (N = `param1`) | Multi-select of event participants |
| 4 (Binary Selection) | Template name as-is | 2 participant outcomes | Two participant selects |

## Files to Create

### 1. `app/Filament/Resources/MarketResource.php`

Hidden from navigation (`$shouldRegisterNavigation = false`), same pattern as ResultResource.

**Form** (single Section with 2 columns):

| Field | Type | Visibility | Notes |
|-------|------|-----------|-------|
| `event_id` | Hidden | Always | Pre-filled from URL param |
| `market_template_id` | Select (relationship) | Always | Filtered by tournament config. `reactive()`. On change: populate `market_type_id`, `description` |
| `market_type_id` | Hidden | Always | Set from selected template's `market_type_id` |
| `description` | TextInput | Always | Readonly. Auto-generated: template name for types 1/3/4, template name + participant for type 2 |
| `participant_id` | Select (relationship) | Type 2 only | Single participant from event. On change: update `description` |
| `participant_ids` | Select (multiple, non-DB) | Type 3 only | Select up to `param1` event participants |
| `participant_a_id` | Select (non-DB) | Type 4 only | First participant |
| `participant_b_id` | Select (non-DB) | Type 4 only | Second participant |

**Table**: `id`, `description` (searchable), `marketTemplate.name`, `marketType.name` (toggleable), `created_at`, `updated_at`. Filter by `event_id` (relationship filter).

**Actions**: `EditAction`, `DeleteBulkAction`.

**Pages**: ListMarkets, CreateMarket, EditMarket.

### 2. `app/Filament/Resources/MarketResource/Pages/ListMarkets.php`

Standard ListRecords page with CreateAction header. Accepts `tableFilters` with `event_id` to pre-filter.

### 3. `app/Filament/Resources/MarketResource/Pages/CreateMarket.php`

Custom CreateRecord page. Overrides `mutateFormDataBeforeCreate()` to:
1. Remove non-DB fields (`market_type_id`, `participant_ids`, `participant_a_id`, `participant_b_id`)
2. After save: auto-create outcomes based on `market_type_id`:
   - Type 1: Create two outcomes with `outcome_type_id` = yes-type and no-type IDs from template
   - Type 2: Same as Type 1
   - Type 3: Create one outcome per selected participant (from `participant_ids`)
   - Type 4: Create two outcomes for `participant_a_id` and `participant_b_id`

### 4. `app/Filament/Resources/MarketResource/Pages/EditMarket.php`

Standard EditRecord page with DeleteAction header.

## Helper Methods (in MarketResource)

### `getEventParticipants(int $eventId): array`
Returns `Participant::whereHas('events', fn($q) => $q->where('events.id', $eventId))->pluck('name', 'id')->toArray()`

### `getAvailableTemplates(Event $event): Builder`
Traces: `$event->tournament->config->market_template_ids` → returns `MarketTemplate::whereIn('id', $ids)`

### `getOutcomeTypeIds(MarketTemplate $template): array`
Returns `$template->outcome_type_ids` (JSON array containing IDs of yes/no/participant types)

### `autoCreateOutcomes(Market $market, array $data): void`
Core logic per market type — creates Outcome records.
