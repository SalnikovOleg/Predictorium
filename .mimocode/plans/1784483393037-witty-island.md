# Plan: Add "Add all default" Button to MarketResource

## Overview
Add a button "Add all default" next to "New Market" on the ListMarkets page. Clicking it bulk-creates markets for all templates configured in the tournament, with appropriate outcomes based on market type.

## Changes

### 1. Add `createDefaultsMarket()` to `MarketService`

**File:** `app/Services/Trading/MarketService.php`

```php
public function createDefaultsMarket(int $eventId): int
```

Logic:
1. Load Event → Tournament → TournamentConfig → `market_template_ids`
2. Load all MarketTemplates by those IDs
3. For each template, check if a Market with that `market_template_id` already exists for this `event_id` — skip if so
4. Create the Market record (with `description` from template name)
5. Create outcomes based on `market_type_id`:
   - **Type 1 (Boolean):** Create Yes + No outcomes from `outcome_type_ids` (lookup OutcomeType by IDs)
   - **Type 3 (Selection):** Create one outcome per event participant (participant outcome type, coef=1.00)
   - **Other types:** Create market without outcomes
6. Wrap all in `DB::transaction`
7. Return count of created markets

## Implementation Details

### MarketService::createDefaultsMarket(int $eventId): int

```php
public function createDefaultsMarket(int $eventId): int
{
    return DB::transaction(function () use ($eventId) {
        $event = Event::with('tournament.config')->findOrFail($eventId);
        $templateIds = $event->tournament->config->market_template_ids ?? [];
        
        if (empty($templateIds)) {
            return 0;
        }
        
        $templates = MarketTemplate::whereIn('id', $templateIds)->get();
        $created = 0;
        
        foreach ($templates as $template) {
            if ($this->repository->existsByEventAndTemplate($eventId, $template->id)) {
                continue;
            }
            
            $market = Market::create([
                'event_id' => $eventId,
                'market_template_id' => $template->id,
                'description' => $template->name,
            ]);
            
            $this->createOutcomesForMarket($market, $template, $event);
            $created++;
        }
        
        return $created;
    });
}
```

### Outcome creation per market type

```php
private function createOutcomesForMarket(Market $market, MarketTemplate $template, Event $event): void
{
    $marketTypeId = (int) $template->market_type_id;
    
    if ($marketTypeId === 1) {
        // Boolean: create outcomes from template's outcome_type_ids
        $outcomeTypeIds = $template->outcome_type_ids ?? [];
        foreach ($outcomeTypeIds as $typeId) {
            Outcome::create([
                'market_id' => $market->id,
                'outcome_type_id' => $typeId,
                'coef' => 1.00,
            ]);
        }
    } elseif ($marketTypeId === 3) {
        // Selection: create one outcome per event participant
        $participantTypeId = OutcomeType::where('name', 'participant')->first()->id;
        $participantIds = $event->participants()->pluck('participants.id');
        foreach ($participantIds as $participantId) {
            Outcome::create([
                'market_id' => $market->id,
                'outcome_type_id' => $participantTypeId,
                'participant_id' => $participantId,
                'coef' => 1.00,
            ]);
        }
    }
    // Types 2, 4: create market without outcomes
}
```

### ListMarkets header action

```php
protected function getHeaderActions(): array
{
    return [
        Actions\CreateAction::make()
            ->url(fn () => static::getResource()::getUrl('create', [
                'event_id' => request()->query('tableFilters')['event_id'] ?? null,
            ])),
        Actions\Action::make('createDefaultsMarket')
            ->label('Add all default')
            ->icon('heroicon-o-sparkles')
            ->requiresConfirmation()
            ->modalHeading('Create Default Markets')
            ->modalDescription('Create markets for all templates configured in this tournament. Existing markets will be skipped.')
            ->action(function () {
                $eventId = request()->query('tableFilters')['event_id'] ?? null;
                if (! $eventId) {
                    return;
                }
                
                $service = app(MarketService::class);
                $count = $service->createDefaultsMarket((int) $eventId);
                
                Notification::make()
                    ->title("Created {$count} default market(s)")
                    ->success()
                    ->send();
            })
            ->visible(fn () => ! empty(request()->query('tableFilters')['event_id'])),
    ];
}
```
